# PRD: FinSight

## 목표
카드·은행 CSV 명세서를 업로드하면, 어디에 얼마를 쓰는지와 새는 돈이 어디인지를 한 화면에서 보여준다.

## 사용자
가계부 앱을 몇 번 시도했다 포기한 개인, 그리고 사업·개인 지출이 한 카드에 섞여 있는 프리랜서. 매달 명세서를 받아보긴 하지만 열어보지 않는 사람들.

## 핵심 기능

1. **CSV 업로드 & 정규화**
   카드사·은행마다 다른 컬럼 이름과 인코딩(UTF-8/CP949)을 자동 인식해 공통 거래 스키마로 변환한다. 거래 내역은 원본 그대로 보관하므로 명세서를 누적할수록 분석이 정확해진다.

2. **카테고리별 지출 분류**
   가맹점명을 Claude가 식사·교통·구독·쇼핑·의료 등으로 분류한다. 분류 결과는 거래에 저장되고, 사용자가 수정하면 그 수정이 유지된다.

3. **기간별 지출 추이**
   월별·주별 총지출과 카테고리별 추이. 전월 대비 증감과 어떤 카테고리가 늘었는지 보여준다.

4. **구독 누수 / 이상 거래 탐지**
   동일 가맹점에 일정 주기·유사 금액으로 반복 결제되는 건을 찾아 "구독"으로 묶고, 최근에 안 쓰는데 계속 빠져나가는 건(누수 후보)을 표시한다. 평소 패턴에서 크게 벗어난 금액은 이상 거래로 표시한다.

5. **AI 요약 & 절약 인사이트**
   위 집계 결과를 근거로 Claude가 한국어 요약과 구체적인 절약 제안을 만든다. "식비를 줄이세요" 같은 일반론이 아니라 "지난달 배달 앱 결제 18건 ₩342,000, 전월 대비 +41%" 처럼 숫자에 붙은 제안.

6. **구독 결제 (Polar)**
   무료/유료 플랜 구분. 자세한 경계는 아래 요금제 참조.

7. **계정 수명 관리**
   비밀번호 재설정, 이메일 미인증 상태 안내, 계정 삭제(전 데이터 cascade). 거래 원문을 전량 보관하므로 지울 수 있는 경로가 반드시 있어야 한다.

전체 화면 전이·상태·유스케이스는 `phases/0-mvp/USER_JOURNEY.md`에 있다.

## 요금제

명세서는 월 1회 나오므로 **분석 횟수 제한은 의미가 없다.** 대신 데이터 보관 기간과 기능으로 나눈다.

| | Free | Pro |
|---|---|---|
| 업로드 / 분석 횟수 | 무제한 | 무제한 |
| 데이터 보관 | 최근 **3개월** | 무제한 |
| 카테고리별 분류 | ✅ | ✅ |
| 기간별 지출 추이 | 최근 3개월만 | 전 기간 |
| 구독 누수 / 이상 거래 탐지 | **건수·총액만** | 전체 목록 |
| AI 요약 & 절약 인사이트 | ❌ | ✅ |
| 데이터 내보내기 (CSV) | ❌ | ✅ |

보관 기간을 넘긴 거래는 삭제하지 않고 **조회에서 가림**(Free 상태에서 3개월 초과 데이터는 잠금 표시). 업그레이드하면 즉시 다시 보인다 — 데이터를 인질로 잡는 대신, 이미 쌓인 이력이 업그레이드 동기가 되게 한다.

구독 탐지와 이상 거래는 Free에서도 **"반복 결제 12건, 월 ₩84,300" / "이상 거래 3건"** 처럼 실제 계산한 요약을 보여주고 세부 목록만 잠근다(ADR-010). 첫 방문에 가치를 전혀 못 보면 재방문이 없고, 반복 결제는 3회 이상 누적돼야 탐지되므로 재방문이 곧 제품 가치다.

## MVP 제외 사항
- 은행/카드사 실시간 API 연동 (오픈뱅킹, 스크래핑)
- 예산 설정 및 초과 알림 (이메일/푸시)
- 팀·가족 공유 계정
- 다중 통화 및 환율 변환
- 모바일 앱 (반응형 웹으로만 대응)
- 영수증 이미지 OCR

## 디자인
- 다크모드 고정. 마케팅 사이트가 아니라 매달 여는 도구처럼 보여야 한다.
- 무채색 기반 + 포인트 1색(청록). 지출/절감을 나타내는 시맨틱 색상 2개.
- 숫자가 주인공이다. 장식보다 정렬과 대비를 우선한다.
