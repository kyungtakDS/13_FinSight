# UI 디자인 가이드

## 디자인 원칙
1. **도구처럼 보여야 한다.** 마케팅 페이지가 아니라 매달 여는 대시보드다.
2. **숫자가 주인공이다.** 장식보다 정렬·대비·여백으로 위계를 만든다. 큰 숫자 하나가 차트 하나보다 나을 때가 많다.
3. **모든 수치는 근거로 되돌아갈 수 있어야 한다.** 집계 숫자는 원본 거래 목록으로 드릴다운된다. 출처 없는 숫자를 보여주지 않는다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

### 브랜드 액센트
`#14b8a6` (청록, 카드 위 대비 7.4). 링크·포커스 링·활성 탭·Pro 배지에 쓴다.
**차트 플롯 영역 안에서는 쓰지 않는다** — 카테고리 시리즈 색과 혼동되기 때문.

### 카테고리 시리즈 (지출 분류)
아래 8슬롯을 **고정 순서로** 배정한다. 순환시키지 않는다. 9번째 카테고리는 "기타"로 접는다.

| 슬롯 | 카테고리 | 값 |
|---|---|---|
| 1 | 식비 | `#3987e5` |
| 2 | 교통 | `#d95926` |
| 3 | 구독 | `#199e70` |
| 4 | 쇼핑 | `#c98500` |
| 5 | 의료 | `#d55181` |
| 6 | 주거·공과금 | `#008300` |
| 7 | 문화·여가 | `#9085e9` |
| 8 | 기타 | `#e66767` |

`#141414` 표면 기준 검증 통과 — 명도 밴드, 채도 하한, CVD 인접 분리(최악 ΔE 8.4), 정상시야 하한(19.3), 대비 전 슬롯 3:1 이상. 색을 바꾸면 반드시 재검증한다:
```
node scripts/validate_palette.js "<hex,...>" --mode dark --surface "#141414"
```
CVD ΔE가 6~8 밴드이므로 **보조 인코딩이 필수**다 — 범례는 항상 있고, 4개 이하일 때는 직접 라벨도 붙인다. 색만으로 구분되게 두지 않는다.

산점도·버블처럼 모든 쌍이 인접한 형태에서는 **앞 3슬롯까지만** 쓰고 나머지는 "기타"로 접거나 small multiples로 쪼갠다.

### 상태 / 델타 색상
| 용도 | 값 |
|------|------|
| 절감 · 감소 (좋음) | `#0ca30c` |
| 주의 (구독 누수 후보) | `#fab219` |
| 이상 거래 (심각) | `#d03b3b` |

상태 색은 **아이콘 + 라벨과 함께** 쓴다. 색만으로 의미를 전달하지 않는다. 슬롯 6 시리즈 그린(`#008300`)과 상태 그린(`#0ca30c`)은 색 차이가 작으므로 같은 화면에 둘 때는 반드시 라벨로 구분한다.

지출 증감 표기: 증가는 `#d03b3b`, 감소는 `#0ca30c`. 화살표 아이콘을 동반한다.

## 차트 규칙

- **이중 축(y축 2개) 금지.** 스케일이 다른 두 지표는 차트를 둘로 나누거나 공통 기준으로 지수화한다.
- 색은 **엔티티**를 따른다. 필터로 시리즈 수가 줄어도 남은 시리즈의 색은 바뀌지 않는다.
- 연속형(히트맵 등)은 단일 색조 밝기 램프. 무지개 색상 금지.
- 마크: 선 2px, 마커 8px 이상, 막대 데이터 끝 4px 라운드(기준선 쪽은 각지게), 인접 채움 사이 2px 표면 간격.
- 그리드·축은 후퇴시킨다. 데이터보다 눈에 띄면 안 된다.
- **호버 레이어는 기본 탑재.** 선/영역 차트는 크로스헤어 + 툴팁, 막대/셀은 마크별 툴팁.
- 모든 점에 숫자를 찍지 않는다. 최댓값·최솟값·최신값만 선택적으로 직접 라벨링한다.
- 차트마다 표 보기 토글을 제공한다.

## 컴포넌트

### 카드
```
rounded-lg bg-[#141414] border border-white/10 p-6
```
지표 카드(KPI)는 `rounded-md`, 차트 카드는 `rounded-lg`, 모달은 `rounded-xl`. 전부 같은 반경을 쓰지 않는다.

### 버튼
```
Primary:   rounded-md bg-white text-black font-medium hover:bg-neutral-200
Secondary: rounded-md border border-white/15 text-white hover:bg-white/5
Text:      text-neutral-400 hover:text-white
Accent:    text-[#14b8a6] hover:underline    (링크 전용)
```

### 입력 필드
```
rounded-md bg-[#0a0a0a] border border-white/10 px-3 py-2
focus:border-[#14b8a6] focus:outline-none
```

### 업로드 드롭존
```
rounded-lg border border-dashed border-white/15 bg-[#141414] p-10
드래그 오버: border-[#14b8a6] bg-[#14b8a6]/5
```

## 레이아웃
- 전체 너비: `max-w-6xl` (대시보드), `max-w-5xl` (랜딩)
- 좌측 정렬 기본. 히어로 섹션 외에는 중앙 정렬 금지.
- 간격: 카드 내부 `gap-3`, 카드 사이 `gap-4`, 섹션 사이 `space-y-10`

## 타이포그래피
시스템 산세리프만 쓴다: `system-ui, -apple-system, "Segoe UI", sans-serif`. 디스플레이체·세리프체를 도입하지 않는다.

| 용도 | 스타일 |
|------|--------|
| 페이지 제목 | `text-3xl font-semibold text-white tracking-tight` |
| 히어로 숫자 | `text-5xl font-semibold text-white` |
| 카드 제목 | `text-sm font-medium text-neutral-400` |
| 본문 | `text-sm text-neutral-300 leading-relaxed` |
| 표 셀 / 축 눈금 | `text-xs text-neutral-400 tabular-nums` |

금액은 `₩1,234,567` 형식. 표·축처럼 세로 정렬이 필요한 곳에만 `tabular-nums`를 쓰고, 히어로 숫자에는 쓰지 않는다.

## 애니메이션
- 허용: fade-in (0.2s), 차트 진입 시 1회 그리기 (0.4s), 호버 색 전환 (0.15s)
- 그 외 모든 애니메이션 금지. 특히 반복 재생되는 것, 스크롤 연동 패럴랙스, 숫자 카운트업.

## 아이콘
- SVG 인라인, `strokeWidth 1.5`, 16px 또는 20px
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다
- 이모지를 UI에 쓰지 않는다
